# Rin

Rin は、ホストプログラムに組み込んで安全に実行できる、小さな純粋 Lisp 系言語である。すべての値は不変であり、I/O や環境への暗黙の権限を持たない。

## 背景

Rin は、Suz の [#141](https://github.com/TappoyGK/suz/issues/141) で提案された評価器である。Suz の言語仕様（所有権・`arena`・C23 出力）を肥大化させずに、次の 2 つの用途を 1 つの小さな仕組みで実現することを目的とする。

1. **コンパイル時の定数・テーブル計算（comptime）**：三角関数テーブル、CRC テーブル、ビットマップなどをコンパイル時に生成する。
2. **ゲームの Mod・組み込みスクリプト**：安全なサンドボックスの中でスクリプトを実行する。

どちらの用途も、「ホストから値を受け取り、純粋に値を返す」という同じモデルで扱う。ホストの状態を変えたい場合は、Rin からホストの関数を呼ぶのではなく、実行したい操作を表す値を戻り値として返し、ホスト側で実行する。

この目的から、Rin は次の性質を保つ。

- I/O や環境への暗黙の権限を持たない。権限が必要な機能は、ホストが明示的に許可した場合に限って使える。
- 資源（ステップ数・メモリ・再帰の深さ）に上限があり、上限を超えた場合や誤りがあった場合も、ホストを停止させずにエラーとして返す。
- ホストから渡されたアロケータ（`arena` を含む）の上で動く。
