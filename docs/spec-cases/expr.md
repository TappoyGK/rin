# 式と構文の仕様例

### expr-001 defn による再帰定義と match 照合

主根拠：`[expr.defn]`

**入力：**

```rin
(defn fact (n)
  (if (<= n 1) 1 (* n (fact (- n 1)))))
(fact 5)
```

**期待結果：**

| 上限 | 結果 | 値 |
|---|---|---|
| 既定 | 値 | `120` |

### expr-002 無名関数のレキシカル環境捕捉

主根拠：`[expr.fn]`

**入力：**

```rin
(let (base 10)
  (let (add_base (fn (x) (+ x base)))
    (add_base 5)))
```

**期待結果：**

| 上限 | 結果 | 値 |
|---|---|---|
| 既定 | 値 | `15` |

### expr-004 構造体の構築・フィールド参照・with による不変更新

主根拠：`[expr.with]`

**入力：**

```rin
(let (c1 Card { id: "strike", cost: 1 })
  (let (c2 (with c1 { cost: 0 }))
    (+ c1.cost c2.cost)))
```

**期待結果：**

| 上限 | 結果 | 値 |
|---|---|---|
| 既定 | 値 | `1` |
