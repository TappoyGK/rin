# 字句の仕様例

### lex-001 隣接する添字アクセスとリテラルリストの区別

主根拠：`[src.attached]`

**入力：**

```rin
(let (xs [10 20 30])
  (+ xs[0] xs[(+ 1 1)]))
```

**期待結果：**

| 上限 | 結果 | 値 |
|---|---|---|
| 既定 | 値 | `40` |
